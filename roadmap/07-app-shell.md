# 07. Каркас приложения

**Цель:** настоящее приложение `apps/client` на React + Tauri + веб: навигация из макетов, раздел заметок с деревом
и редактором, локальные наборы и карточки — всё без сервера и аккаунта.

Связь с решениями: 2.1–2.3, раздел 4 (UI, состояние), 6.3 (производительность).

## Что изучить

- Reatom: <https://reatom.dev> — атомы, действия, асинхронность, роутинг, формы, привязка к React. Проверь, какая
  версия актуальна, и читай документацию именно её.
- `react-components` и `ui-kit-react` из `flippo-ui` — их `AGENTS.md`, Storybook, как подключаются стили.
- Виртуализация списков: TanStack Virtual — <https://tanstack.com/virtual/latest>.
- i18n: любая лёгкая библиотека (например, i18next) или свой минимальный слой — реши сам и запиши почему.
- Макеты: `design/` (главная, коллекция, набор, карточка, настройки; мобильные экраны).

## Шаги

1. `apps/client`: Vite + React + TS + Tauri 2 (`src-tauri/`). Одна сборка работает и в Tauri, и в браузере.
2. `packages/platform-tauri` и `packages/platform-web`: реализации интерфейсов из `platform-contracts`
   (используй код P1 и P2, но перепиши начисто). Выбор реализации — при старте приложения.
3. Подключи `ui-kit-react` и стили `component-styles`, тему (светлая/тёмная) и RU/EN.
4. Маршруты: «Главная», «Сообщество» (пока заглушка), «Коллекция» (наборы и папки), «Набор», «Заметки»,
   «Настройки». Боковая панель с недавними наборами и папками; на телефоне — нижняя навигация, как в макетах.
5. Раздел «Заметки»: выбор/создание хранилища, дерево папок (создать, переименовать, переместить, удалить),
   редактор из P3 (перенеси в `packages/editor`), быстрый переход `Ctrl+O`, обратные ссылки справа.
6. Набор (пока локальный): список карточек, поля «заголовок / ответ / подсказки / подробнее» на том же редакторе,
   «+» между карточками, оглавление справа, фильтры, импорт из буфера и CSV.
   **Производительность:** набор из 500 карточек; редактор создаётся только для карточки в фокусе, остальные —
   лёгкий HTML; список виртуализирован; атом на карточку.
7. Связь «заметка ↔ карточка»: из карточки — «прикрепить заметку» (ссылка дописывается в файл заметки), из заметки —
   «создать карточку из выделения».
8. Пустые состояния и ошибки по макетам.
9. Нарисуй в Figma (или набросай) недостающие экраны заметок, которые тебе понадобились, — или отметь их в
   `roadmap/notes/design-gaps.md`.

## Готово, когда

- [ ] Приложение работает в Tauri на десктопе, в браузере и на Android (iOS — если есть доступ к Mac).
- [ ] Можно вести хранилище заметок и локальные наборы без сети и без аккаунта; после перезапуска всё на месте.
- [ ] Ввод в карточке набора из 500 карточек без лагов (проверь Profiler React: при вводе перерисовывается только
      текущая карточка).
- [ ] Связи заметка ↔ карточка работают в обе стороны.

## Ловушки

- Не клади текст редактора в атомы на каждое нажатие клавиши. Источник текста — редактор (позже Yjs).
- Не пиши платформенные `if (isTauri)` по всему коду — только через `platform-contracts`.
