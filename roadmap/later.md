# После MVP

Короткие ориентиры. Подробные этапы распиши, когда дойдёшь до них, — к тому времени многое станет понятнее.

## Итерация 2

- **ИИ внутри Flippo** (токен пользователя): карточки из заметки или выделения, проверка ответа, связанные
  заметки. Все действия — через команды домена из этапа 06. Токен хранится в `KeyStore`.
- **MCP-сервер** для внешних агентов: доступ к локальному хранилищу и наборам. Изучить: спецификация MCP
  <https://modelcontextprotocol.io>.
- **Содержимое заметок, уровни 3–4**: таблицы (самое трудоёмкое в live preview), KaTeX, callouts, PDF и аудио.
- **Адаптеры хранения**: S3, Google Drive, WebDAV — плагинами на интерфейсе `StorageAdapter` из этапа 11.

## Дальше

- **Сообщество**: каталог публикаций, поиск с русской морфологией, «Популярное» и «Новое», модерация (жалобы,
  скрытие, блокировка, ограничение частоты).
- **Граф знаний**: визуализация связей из индекса; окружение заметки, фильтры.
- **Публичная платформа плагинов**: стабилизация API, загрузка сторонних плагинов, права плагинов.
- **Самостоятельный хостинг**: пакет docker-compose и документация.
- **Оплата синхронизации** с учётом регионов и правил сторов.
- **Поиск по смыслу** (векторные представления).
- **Доверенный контакт** для восстановления доступа.
