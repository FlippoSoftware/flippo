# 13. Сборки и выпуск

**Цель:** воспроизводимые сборки всех платформ в CI, подписанные приложения, сервер в продакшене, обновления.

## Что изучить

- Распространение Tauri: <https://v2.tauri.app/distribute/> — подпись для Windows и macOS, App Store, Google Play,
  автообновление (плагин updater).
- GitHub Actions для Tauri: официальный `tauri-action`.
- Требования сторов: App Store Review Guidelines (вход через Apple, встроенные покупки), политика Google Play.
- Эксплуатация Go-сервиса: метрики (Prometheus), трассировка (OpenTelemetry), бэкапы SurrealDB и S3.

## Шаги

1. CI: линтеры и тесты всех частей (Go, Rust, TS) на каждый PR.
2. CI: сборки Windows, macOS, Linux, Android, iOS, веб; артефакты сохраняются.
3. Подпись: сертификат для Windows, Apple Developer ID и нотаризация для macOS, ключи для Android и iOS.
4. Автообновление десктопа.
5. Продакшен-сервер: docker-compose или другой оркестратор, TLS, бэкапы базы и S3 с проверкой восстановления,
   мониторинг, алерты.
6. Миграции локальной базы клиента: версия схемы, обновление без потери данных (тест: установить старую версию,
   создать данные, обновиться).
7. Политика конфиденциальности и условия использования; решить вопросы из раздела 9 решений про регионы хранения
   данных.
8. Бета-тест: TestFlight, внутреннее тестирование Google Play, несколько студентов.

## Готово, когда

- [ ] Один тег в git → сборки всех платформ и выкладка сервера без ручных шагов (кроме подписи, если нужно).
- [ ] Восстановление сервера из бэкапа проверено на практике.
- [ ] Обновление клиента со старой версии не теряет данные.
